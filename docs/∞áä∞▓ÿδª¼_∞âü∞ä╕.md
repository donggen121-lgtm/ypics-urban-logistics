| 파일 | 내용 |

| 수요_2027_행정동.csv | **최적화 입력.** 424개 행정동 × `d_{저성장,기준,고성장}_{평상일,피크일}`, 신선 `fresh_…` (개/일) |
| 시나리오_2027.csv | 6개 시나리오(성장 3 × 날 2)와 확률 |
| 수요예측_검증.csv | 모형 비교(MAPE) |
| forecast_chart.png | 전국 추이·시나리오, 자치구별 하루 수요 |

계산 순서
1. 전국 물동량(2018~2025 실적, 2025 = 64.18억 개) → 2027 시나리오
   - 검증: 2018~2023 학습 → 2024·2025 예측. 감쇠추세 3.4%, 로그선형 3.2%, 최근3년 CAGR 3.5% (MAPE)
   - 2025 성장률이 7.8%로 꺾여서(22.5→15.5→7.8%) 시나리오로 둔다: 저 4%/년(69.4억), **기준 7.8%/년(74.5억)**, 고 = 감쇠추세 11.7%/년(80.1억). 확률 0.25/0.5/0.25
2. 서울 비중 18.97% (2023 실적 19.5%와 2018~2023 추세 연장값의 중간) → 서울 2027 연간 13.2 / **14.1** / 15.2억 개
3. 자치구 비중: 2018~2022 학습 → 2023 검증. 직전년도 유지 1.08%, 선형추세 2.21%, **직전년도×인구증감 0.96%** (MAPE) → 2023 비중 × (2027/2023 장래인구)
4. 하루 수요: 연간 ÷ 365 × 1.401(2023 평일 평균 ÷ 연 일평균, 공휴일 제외) = 평상일. 피크일 = 평상일 × 자치구별 피크계수(평일 상위 5% ÷ 평일 평균, 서울 1.475)
5. 신선: 자치구 '식품' 비중(서울 23.9%) × 0.267(2023 온라인 식품 거래액 중 농축수산물 비율)
6. 행정동: 자치구 수요 × 구내_야간비중
- 기준 평상일 서울 하루 542만 개(신선 35만), 피크일 801만 개
