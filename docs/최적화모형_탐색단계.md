# 도심 물류센터 입지 최적화 모형 (scripts/09_optimize.py)

## 실행
```
pip install highspy pandas scipy           # 무료 솔버 HiGHS
python scripts/09_optimize.py               # 기준안 (약 1~2분)
python scripts/09_optimize.py --solver gurobi   # Gurobi 학생 라이선스가 있으면
python scripts/10_ucurve.py                 # 센터 수별 비용(U자 곡선) + 민감도
python scripts/11_plot_results.py           # 그림
```
옵션: `--T 15`(서비스 수준), `--tt tt25_h18`(시간대), `--far 2`(복층), `--dens 8`, `--penalty_min 30`, `--fixed 1`(센터당 고정운영비 억/년), `--nnew 50`(신규 수 고정), `--general 0`(신선 전용 센터망), `--fresh 0`(신선 제외), `--tag 이름`

## 수식
집합: I = 기존센터 27(개설 고정) ∪ 신규 후보 815(공영주차장·주유소, 좌표·도로연결·임대료 확인된 곳), J = 행정동 424, S = 시나리오 6(성장 저/기준/고 × 평상일/피크일), A_j = T분 안 기존센터 전부 ∪ T분 안 신규 후보 중 가까운 30곳

1단계(지금 결정): y_i 개설, z_i 냉장 설비 (0/1)
2단계(수요 확인 후): x_ijs, w_ijs 일반·신선 배정량(개/일), u_js, v_js 외곽 터미널로 넘기는 물량

min Σ_i R_i y_i + Σ_i 0.87·R_i z_i + Σ_s p_s·DAYS·[ Σ_ij cθ·t_ij (x_ijs + w_ijs) + P·Σ_j u_js + 1.5P·Σ_j v_js ]

s.t.
- Σ_{i∈A_j} x_ijs + u_js = d_js (일반 수요),  Σ_{i∈A_j} w_ijs + v_js = f_js (신선 수요)
- Σ_j (x_ijs + w_ijs) ≤ Cap_i y_i (용량),  Σ_j w_ijs ≤ Cap_i z_i,  z_i ≤ y_i (신선은 냉장센터만)
- Σ_{i: t_ij ≤ T} y_i ≥ 1 ∀j (서비스 수준: 모든 동이 20분 안 센터 커버)
- Σ_{i: t_ij ≤ T} z_i ≥ 1 ∀j (신선 서비스 수준: 20분 안 냉장센터)

| 기호 | 값 |
|---|---|
| R_i | 면적 × 공시지가 × 5.5% (기존센터 0) |
| Cap_i | 면적 × 4개/㎡·일 |
| cθ | 420원/분 × 2/170 = 4.94원/개·분 |
| P | 외곽 터미널 편도 45분 × 4.94 = 222원/개 (신선 1.5배) |
| DAYS | 365/1.401 = 260.5 (평일 환산 연 일수) |
| t_ij | 11시 평일 최단 이동시간(분) |

## 비교 대상
- 현상유지: 기존 27곳만, 나머지는 외곽 배송 (커버 제약 없음)
- EV: 평균 수요(6개 시나리오 확률가중) 하나로 푼 결정론 모형
- RP: 2단계 확률모형
- EEV: EV 입지를 고정하고 6개 시나리오에서 2단계만 다시 푼 비용 → VSS = EEV − RP
