# 최적화 모형 (결정론, `scripts/12_run_compare.py`)

용량 제약 시설입지 문제(CFLP)에 서비스 수준 커버 제약과 품목 2종(일반·신선)을 더한 혼합정수계획이다.
2027년 기준 시나리오 평상일 수요 하나로 푼다. (2단계 확률계획 버전은 `09_optimize.py`, 탐색 단계 기록은 `최적화모형_탐색단계.md`)

## 집합
- I = I^E ∪ I^N : 센터 후보. I^E 기존 택배센터 27곳, I^N 신규 후보(주유소·공영주차장)
- J : 수요지, 행정동 424곳
- A_j : 동 j 에 배송할 수 있는 센터 = 이동시간 T분 이내 기존 센터 전부 ∪ T분 이내 신규 후보 중 가까운 30곳

## 파라미터
| 기호 | 뜻 | 값 |
|---|---|---|
| d_j, f_j | 동 j 의 하루 일반·신선 수요(개/일) | 2027 기준 평상일, 서울 합계 542만 개 (신선 35만) |
| t_ij | 센터 i → 동 j 최단 이동시간(분) | View-T 2025 평일 11시 |
| T | 서비스 수준 | 20분 |
| R_i | 연 임대료 = 부지면적 × 공시지가 × 5.5% | 기존 센터 0 |
| g_i | 연 고정 운영비 | 신규, 용량 1만 개/일 미만 1억 / 이상 2억 원 |
| κ | 저온 임대료 배수 | 1.87 |
| Cap_i | 하루 처리 용량 = 부지면적 × 4개/㎡ | 복층 없음 |
| c | 1개·1분당 배송비 = 380원/분 × 2/170 | 4.47원 |
| P, P^F | 외곽 터미널 배송비(일반, 신선) | 편도 45분 → 201원, 302원/개 |
| D | 연 환산 일수 = 365 / 1.401 | 260.5일 |

## 결정변수
- y_i ∈ {0,1} 센터 개설, z_i ∈ {0,1} 냉장 설비
- x_ij, w_ij ≥ 0 일반·신선 배정 물량(개/일)
- u_j, v_j ≥ 0 서울 센터가 처리하지 못해 외곽 터미널에서 배송하는 일반·신선 물량

## 목적함수 (연간 총비용 최소화)
```latex
\min \sum_{i\in I}(R_i+g_i)\,y_i + \sum_{i\in I}(\kappa-1)R_i\,z_i
 + D\Big[\sum_{j\in J}\sum_{i\in A_j} c\,t_{ij}(x_{ij}+w_{ij}) + P\sum_{j} u_j + P^F\sum_{j} v_j\Big]
```

## 제약식
```latex
\begin{aligned}
&\textstyle\sum_{i\in A_j} x_{ij} + u_j = d_j && \forall j && \text{일반 수요 충족}\\
&\textstyle\sum_{i\in A_j} w_{ij} + v_j = f_j && \forall j && \text{신선 수요 충족}\\
&\textstyle\sum_{j:\,i\in A_j} (x_{ij}+w_{ij}) \le Cap_i\,y_i && \forall i && \text{처리 용량}\\
&\textstyle\sum_{j:\,i\in A_j} w_{ij} \le Cap_i\,z_i,\quad z_i \le y_i && \forall i && \text{신선은 냉장 센터만}\\
&\textstyle\sum_{i:\,t_{ij}\le T} y_i \ge 1,\quad \sum_{i:\,t_{ij}\le T} z_i \ge 1 && \forall j && \text{20분 안 센터·냉장 센터}\\
&y_i = 1,\ z_i = \text{현재 냉장 여부} && \forall i\in I^E && \text{기존 센터 고정}
\end{aligned}
```

## 실험
| 실행 | 신규 후보 | 의미 |
|---|---|---|
| 현상유지 | 없음 (기존 27곳만, 커버 제약 없음) | 비교 기준 |
| A | 영업 주유소 | 논문과 같은 후보 유형 |
| C | 영업·휴업·폐업 주유소 + 공영주차장 | 기준안 |

모형 크기(C): 이진변수 약 1,700개, 연속변수 약 3.2만 개, HiGHS로 10초 안팎.
